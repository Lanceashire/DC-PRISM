## 4. 最新版仍存在的问题与修复

### A. 在线评价提前使用探索标签（高）

原 `src/run_p3_p4.py` 将 S_t 放入 t+1 释放队列，却同时把 `y_C[S_sel]` 加入当轮 `X_eval/y_eval` 重新训练。对四数据集、16 seeds 的全部 64 个第一轮状态，`released_ids` 均为空，但各方法归档 Brier 存在差异。

这证明原 `brier_t` 是即时结算后的后验评价，不能同时解释为遵守 t+1 延迟的在线评价。未发现由此导致选择器当轮读取隐藏标签的证据；问题在评价模型。

修复后明确采用“当轮开始、到期反馈释放之后”的在线评价：模型仅在 D_t 拟合，S_t 下一轮可用，O_t 两轮后可用。当轮副本不提前附加 S_t。新增全方法第一轮相同 Brier、逐轮释放与预算验证。Q/C/J 仍属于单独的离线即时结算反事实诊断，不与在线 ALC 混合。

### B. 固定 k 参照求解器未兑现精确性和可行性（高）

原 `solve_fixed_k_minrisk_subset()` 提供 `exact_max_n` 但不使用，只有五种前缀；不按 B 排除返回解。独立随机搜索第 5 个小池即得到反例：n=8、k=3、B=2.8556954547，存在集合 [1,2,4] 的包络 2.8554099137；函数返回 [1,4,6]，包络 3.7099442914，越预算。

这不是从恒等式测试能发现的问题：错误参照同样可以满足 J=C−Q。风险在于把参照称为“同风险最优固定数量集合”，以及据此解释 Q/C 分账。

修复：n≤16 真正枚举；较大池只返回满足预算的候选，并使用可行 M_K 子集回退；未找到时显式报错而不冒称全局不可行。输出固定数量参照的 `EXACT` 或 `FEASIBLE_HEURISTIC` 身份。k=K 时损失和风险都使用同一个 M_K。

### C. 固定 ε 基线未可靠达到自身数量目标（高，影响基线公平解释）

按原实现自己的 `round((1−ε)K_safe)` 规则检查，P4 的 640 条固定 ε 记录有 362 条没有达到目标；平均选中 3.671875、平均目标 4.90625。原因是信息贪心的部分集合可能阻断后续加点，向原集合继续加 M_K 并不能保证补齐。

修复后若局部扩展未达目标，则从可行参照重新构造，保证目标数量。新协议明确选择 `ceil` 整数规则；这个整数规则变动单独登记，不把原先使用 `round` 本身说成数学错误。修复后完整 6,400 行验证包括固定 ε 数量检查。

### D. 快速复现恢复旧结果（中）

原 fast runner 备份正式结果、运行缩减实验、恢复备份，再生成图表。这可以作为非破坏的 smoke 功能，但不能证明正式表由本次运行生成。本次不再依赖这一路径：原 P4 全量重建直接在新目录执行并逐项比较。

新入口只写新目录，不复制旧表来替代新结果，运行清单记录 RUNNING/FAILED/COMPLETE，失败不隐藏。另提供原提交完整重建脚本及语义列哈希供公开复核。

### E. 同分排序跨版本稳定性（中，原环境可复现已通过）

原候选构造用默认 `argsort`，存在大量同分与后续随机重排，跨 NumPy 的同分顺序可影响集合与轮次。修复采用分数、全局 ID 双键；核心前缀也使用稳定排序。它会改变部分原环境候选和轨迹，因此另立修复版本并全量重跑，不能把新哈希写回旧 CSV。

## 5. 仍需限定的主张

风险分数并非已证明的同时概率上界。源码用在样本内拟合概率划分 D 的上半组、固定 Wilson 常数和有效大小 8 的逐坐标 Laplace 分位数；它不是所宣称的 OOF/Clopper–Pearson 过程。真实数据安全结果解释为经验风险代理下的行为。条件独立和同时覆盖都需要额外前提；不能从零次实现超预算倒推保证。

大池 `EXACT_VERIFIED` 由基数上界闭合触发，只证明最大基数，不保证同基数中风险最小。活动实现将该状态改为 `CARDINALITY_CERTIFIED_RISK_HEURISTIC`。其他比较也应承认有限候选族和启发式参照范围。

`BAIT-Cost-Safe` 是本包的静态 Fisher-trace/cost 贪心适配；`Orig-PA` 是局部适配，不是旧完整 PA 的逐位复现；迁移模型是自写 boosted stumps，不是 XGBoost。结果表保留旧方法键以便对照，正文必须使用这些限定。

NoGate 同时去掉分位数目标、数量惩罚等；ValueUCB 同时改变曲率权重与分位数方向。比较支持方法变体差异，不能各自作为 Gate 或悲观性单一模块的纯因果消融。需要这种主张时才增加共候选族、共权重的单因素试验，本次不通过改参数追求显著性。

最新 README 仍有未同步数字，例如其 P2 DC 数值 0.123585 与当前 `p2_policy_summary.csv` 的 0.120234 不同；HMEQ 的部分“优于”描述也不符合 ALC 汇总。因此新的正文从 CSV 生成，不把“Final/Frozen/Audit-Compliant”字样当作验收证据。

来源脚本目前是根据常量和 NPZ 写描述清单，并未从原 CSV 重建 cohort。已核对 NPZ 精确字节、形状、标签率；原来源与再分发许可仍未独立验证。信用行和个体轨迹留本地。标准化和损失使用的 E 是 D0 分位缩尾代理，并不等于原始货币损失。

P4 的 D0、Q、T 与流由随机排列和协变量分层构造；所谓“历史窗口”是回放中指定的先后角色，不是经原始业务日期验证的真实时间切分。因此 D0-only 的预处理隔离可以成立，但不能据此声称已经完成严格跨年份未来预测或新机构验证。

理论证明另有可修复的代数表述：原文用常见 Bernstein 指数的二次方程反解论证阈值，所写不等式方向不成立；相同数值阈值可由 sub-gamma 矩母函数界直接导出。因此不据此判定包络公式本身错误。正确范围见 `docs/THEORY.md`。

本次在原四数据集、原 4001–4016 seeds 上重新执行修复版，共 6,400 行、640 条方法轨迹。所有第一轮因果时序、释放日程、共同预算、受保护方法可行性、重复探索和固定 ε 数量验证通过。原 P2 和 P3 未重新训练；没有把修复运行称为新独立确认。

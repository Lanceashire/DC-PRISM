# DC-PRISM 论文组织方案

日期：2026-11-04。依据已核对的 GitHub 提交 `a35fc466b4cfdd4783310a3da39f1ea6e88edd8b`、本地覆盖缺口配对诊断和新种子 P4 确认。本文是论文结构与证据使用方案，不改变既有实验、参数或统计协议。

## 1. 统一的研究问题与论文定位

建议用一个问题贯穿全文：

> 在标签只能通过决策获得、且反馈存在延迟的场景中，固定风险预算下应当采集多少标签、选择哪些对象？改变选集组成带来的收益，何时能够补偿采集数量的变化，当前方法又在哪些条件下无法兑现这些收益？

论文采用“问题形式化—具体方法—收益分解—受控证据—真实回放与边界”的路线。核心对象是风险约束下的选择性标签获取。信贷数据提供回放实例；已有完整标签仅供模拟环境在合法释放时点提供反馈以及离线评价使用，不能在选择时作为已知输入。

工作标题建议：

**DC-PRISM: Adaptive Label Acquisition under Risk Constraints and Delayed Feedback**

中文定位：**延迟反馈下风险约束的自适应标签获取：数量与组成权衡。**

中心论点的建议表述：

> 在风险预算与反馈延迟共同作用下，采集数量不足以概括标签集合的学习价值。DC-PRISM 以风险可行的数量参照为基准，通过考虑待反馈信息的集合效用代理调整选择；受控研究支持特定条件下的整体收益，数量—组成分账与真实数据回放进一步揭示其收益来源和适用边界。

“何时少选更好”是贯穿研究的提问，目前的结果提供部分条件证据和失效诊断，尚未得到一个可事前判定、普遍充分必要的规则。摘要和标题不应把这项尚未建立的规律写成已证明结果。

## 2. 三项贡献如何写

以下是可供引言采用的贡献组织；“首次”“独有”等优先权表述，需要相关工作核对后再决定。

1. **决策框架与分析口径。** 在延迟选择性反馈下，把风险可行性、选集数量和信息组成放在同一决策问题中；建立同状态的数量项、组成项和净收益分账，区分一次结算后的学习效果与延迟在线效果。
2. **具体选择方法。** 给出以风险参照为基准的 DC-PRISM：风险可行候选族、Pending-aware 集合信息代理、共同参数抽样下的保守比较，以及显式数量惩罚与回退规则。贡献按完整决策过程叙述，不将每个成熟数学部件都列作独立创新。
3. **条件收益与适用边界的证据。** 通过受控对照、共同候选族组件诊断、真实特征下的覆盖干预及四数据集延迟回放，展示整体收益成立的条件、尚不能独立归因的部分，以及事后收益空间与实际策略收益之间的差距。

数量—组成恒等式本身是代数记账，标准 Bernstein/sub-gamma 工具也是已有基础。它们帮助定义和检验研究问题；论文的新意必须落在问题、具体方法和新的可复核发现上。

## 4. 引言按五段写

**第一段：决策产生数据，数据又影响决策。** 以信用回放引入：只有已接受或主动获取的对象会在约定反馈机制下产生可用标签；未反馈对象的标签不能直接用于训练。因而采集决策同时影响风险暴露与未来模型。

**第二段：数量与价值的冲突。** 在同一风险预算下，较多低风险对象与较少高信息对象可能都可行。已有历史和待反馈对象还会改变新增标签的边际价值。不能仅凭数量最大或个体信息分数最高决定集合选择。

**第三段：提出准确的研究问题。** 我们研究如何在风险约束下联合决定选集组成和采集数量，并通过同状态分解检验学习收益。这里不预设“少选总是更好”，而是把它作为需要用结果回答的问题。

**第四段：方法与分析思路。** 用一个可行的数量参照作比较基准，评价候选集合在待反馈信息到达后的代理价值；共同参数抽样、数量惩罚和阈值控制切换。说明实际标签在决策后按时释放，Q/C/J 在评价端计算。

**第五段：贡献和结果轮廓。** 受控环境整体收益得到支持；真实回放显示异质性；覆盖干预揭示事后改善空间增加不必然变成策略收益。把这个边界当作实际研究发现，避免用一个宽泛的“显著优于基线”覆盖所有实验。

## 5. 形式化与核心公式

### 5.1 两条时间线

决策时间线：到期反馈释放 → 更新可见历史 D_t → 用可见标签与待反馈协变量评分 → 选择 S_t → 将新承诺加入反馈队列。

在线评价：本轮到期反馈释放后、当前新选择标签加入前评价模型。P4 中探索反馈下一轮释放，普通反馈两轮后释放。

离线诊断：锁定选择后，在同一状态上令所比较的 O 与 S 全部结算，再重拟合相同模型、使用相同评价集比较集合。它用于解释集合差异，不替代十轮在线 ALC。

### 5.2 风险可行性

建议用 rho 表示风险包络，用 L 表示预测损失，避免把二者都写为 R。

\[
\rho_\alpha(S)=\sum_{i\in S}E_iq_i+
\sqrt{2\log(1/\alpha)\sum_{i\in S}E_i^2\phi(q_i)}
+\frac{\max_{i\in S}E_i}{3}\log(1/\alpha),
\qquad \rho_\alpha(S)\le B_t.
\]

其中 phi(q)=q(1-q)（q≤1/2）或1/4（q>1/2）；空集包络为零。E 是已登记的归一化暴露代理，B 是数值风险预算，k=|S| 是标签数量。**标签数量减少不等于风险预算占用减少。**

### 5.3 参照与数量—组成分账

M_K 表示本轮返回的风险可行数量参照，K 是其实际数量。若算法给出了最大基数证书，再明确写最大基数；大池参照的风险最小化不能统一称为全局精确最优。M_k 是同状态下数量为 k 的可行风险参照；小池可精确，大池按当前实现记录启发式身份。

对选集 S（|S|=k），定义同状态、相同反馈结算与拟合规则下的损失 L_t(S)：

\[
Q_k=L_t(M_k)-L_t(M_K),\qquad
C_k=L_t(M_k)-L_t(S),\qquad
J=C_k-Q_k=L_t(M_K)-L_t(S).
\]

建议正文称 Q_k 为**有符号数量项**，称 C_k 为**组成收益项**。Q_k 可以为负；现有 P2 均值约为−0.000187，就不支持把数量变化始终解释成损失。

“C_k>Q_k 时 J>0”是由定义成立的判断式。实证贡献来自这些量在何种环境下出现、幅度如何，以及一个不见隐藏标签的选择器是否可以取得收益。不能将代数等价关系写成已解决事前收益预测。

### 5.4 选择分数

设 H 包含历史及待反馈协变量的预期信息，G 表示目标预测分布的权重矩阵，A_S 为选集的信息增量，则集合效用代理为：

\[
V(S)=\operatorname{tr}\{G[H^{-1}-(H+A_S)^{-1}]\}.
\]

对共同参数抽样得到的归一化代理差值 Delta V_m，使用：

\[
\widehat U_\beta(S)=
\operatorname{Quantile}_\beta\{\Delta V_m(S;M_K)\}
-\lambda_K\frac{(K-|S|)_+}{\max(K,1)}.
\]

从风险可行候选族中找评分最高的集合；分数超过阈值 tau 时采用该集合，否则返回 M_K。技术附录写清代码实际采用的 tanh 归一化、2.5尺度、曲率阻尼、抽样数和阈值；以执行代码为准，不照搬其中已过时的注释。

经验参数抽样分位数表达保守比较，不能直接称为真实 Brier 收益的统计置信下界。lambda 数量惩罚也是设计项，不宣称它已经被证明等于 Q_k。

Gate 切换和减少数量分开记录：S≠M_K 与 |S|<K 是不同事件。Gate 通过时也可能只是改变同等数量下的组成。

## 6. 实验按四个研究问题展开

### RQ1：整体方法在受控环境和真实回放中的效果如何？

主在线结果采用现行修复版的新种子 P4：四份现有数据、每份16个随机种子、十轮、十方法。主指标为种子级在线 ALC-Brier；主要比较为 Safe-MinRisk、修复固定 epsilon 和 Fisher-trace/cost 适配，沿用原12项检验家族。

正文表可用方法为行、数据集为列；完整方法、风险参照、固定数量及 Fisher 适配应清晰出现。未使用同一风险保护的旧参照需同时说明风险行为，不能只按 Brier 排名。其余方法完整结果放扩展表。风险包络违反率与实际实现损失分别报告。

真实回放的结论按新种子结果写：PPDai 对固定 epsilon 获得确认，尚未确认对 Fisher 适配的稳定优势。旧修复种子的表现作为复现/稳健性对照，不能逐数据集择优替换主表。

受控整体方法结果可引用 supplement-v1 中 `Package-DC-PRISM` 在128个新受控世界的描述性结果：Brier约0.130807，风险参照约0.147046，Fisher适配约0.153765。该完整包方法比较在原协议中属于次要分析，不补写成事前登记的主要显著性结论。

### RQ2：同状态收益与数量—组成权衡有什么关系？

优先使用现行实现已有的新 P4 离线分账记录，按数据集和种子汇总 Q/C/J；每个种子十轮相关，不能把160轮视为160个独立样本。完整算法有4×16×10=640条记录，全部五个诊断方法共3,200条。

该分账在每个方法自身经历的历史状态上进行，适合解释该方法的局部集合替换。不同方法的轨迹历史已经分叉，不将其跨策略相减冒充共同状态因果比较。

原冻结 P2 的128世界分账可作为受控示例或附录证据：平均 C约0.016262、Q约−0.000187、J约0.016449；其中参照可行性和恒等式已重算。旧算法/求解版本应保留标识，不能把其数值无标签并入现行方法的确认结果。

正文图以 Q/C/J、实际数量差和风险占用关系回答问题。BRP/HRR及收益阈值是补充描述；不能用“释放时为正的比例”替代主要均值与区间。

### RQ3：共同候选族内，各设计因素有什么作用？

采用 supplement-v1 的16因子组合诊断，沿用35项原统计家族。明确标注“DC-PRISM共同候选族诊断变体”，不要与完整搜索算法同名。

报告完整诊断变体对参照的整体收益，以及 Gate、数量惩罚、分位数、Pending 重评分四项独立比较的全部区间。当前结果支持受控整体差异，四项单因素均未定。Pending 对搜索空间的影响不在这一固定族重评分试验的识别范围内。

原A1–A5变体对照与P1参数选择作为补充材料；其中A1/A4并非单一开关消融。文件名含ANOVA的归档表实为分组均值汇总，应按实际计算方式命名和解释。

### RQ4：真实结构与覆盖缺口下，为什么存在收益空间却没有稳定策略收益？

采用 supplement-v1 的真实特征桥接，以及 supplement-v2 的覆盖缺口配对干预，强调不同实验回答的问题。

覆盖干预四个数据/DGP设定各64对，共256个随机配对世界。两组固定X、真概率、标签、风险q、预算及候选族，仅改变可见历史分布；预处理及风险校准保留为正常历史参考组拟合后的冻结对象。

主图并排显示“事后候选族收益空间变化”与“完整诊断规则的实际收益”。四项中三项确认收益空间增加，但未确认完整规则的正收益。Oracle 使用已实现的隐藏训练标签，不把它当作可部署方法的能力上限或下界。

本研究提供对“只有缺口、没有价值”的部分检验，以及对代理未兑现收益的诊断证据；不将该实验写成对整条自然部署管线的唯一失败根因识别。

## 9. 全文统一的十条写作规则

1. 每一项核心主张都能指到具体定义、对照和表格；背景介绍、方法设计和实证结论使用不同强度的动词。
2. 先定义决策信息集和时间线，之后所有选择器、理论条件、实验指标共用这套定义。
3. 明确风险预算B、数量k和信息组成三个概念；不把少选、低风险暴露和Gate触发写成同一个事件。
4. Q是有符号项；J=C−Q是分解；“何时可以事前预测J>0”是更强问题。
